# Compare 2 Files v2.0.0 — 仕様書（取扱説明書）

2つのファイル（またはテキスト）を読み込み、**行単位＋文字単位**の両面で差分を可視化する、ブラウザ動作の単一HTML型ウェブアプリです。あわせて**2つのフォルダを突き合わせる「フォルダ比較」モード**（追加・削除・変更ファイルの検出）も搭載しています。

---

## 1. アプリ概要

| 項目 | 内容 |
| --- | --- |
| 名称 | Compare 2 Files |
| バージョン | v2.0.0 |
| 形式 | 単一 HTML ファイル（`Compare-2-Files.html`）／React 製 |
| 実行環境 | モダンブラウザ（Chrome / Edge / Safari / Firefox 推奨）。インストール・サーバー不要 |
| 対応UI言語 | 日本語 / 英語（切替可・記憶） |
| テーマ | ライト / ダーク（切替可・記憶） |
| データ取り扱い | **すべてブラウザ内で処理**。ファイルはサーバーへ送信されません（プライバシー保護） |

**主な用途**: 契約書・議事録・仕様書などの文書レビュー、コードや設定ファイルの版数比較、ログやCSVの突き合わせ、翻訳・校正前の下書き比較 など。

---

## 2. 特徴（できること）

1. **2ペイン並列比較** — ファイルA（左）とファイルB（右）を横並びで表示し、差分を対応させながら確認できます。
2. **行単位＋文字単位のハイライト** — 「変更」された行は行全体を色付けしつつ、**行の中で変わった文字だけを赤（削除）／青（追加）**で強調します。
3. **日本語対応の類似判定** — `Intl.Segmenter` による形態素分割（日本語/英語対応）を用いた類似度計算。単なる完全一致ではなく「ほぼ同じ行」を変更として拾います。
4. **対応判定しきい値の調整** — 類似度のしきい値をスライダーで変更でき、判定の厳しさをコントロールできます。
5. **Word文書（.docx / .doc）対応** — Wordファイルの中のテキストを抽出して比較できます。
6. **HTMLの文字コード自動判定** — BOM・meta charset・シフトJIS/EUC-JP等を自動判別。手動選択も可能。
7. **一致ブロックの折りたたみ** — 大量の一致行をまとめて非表示にでき、差分だけに集中できます。
8. **同期スクロール** — A/B両ペインのスクロール位置を比率連動（差分表示中）。
9. **HTMLレポート出力** — 比較結果をスタイル付きのHTMLファイルとして保存・共有できます。
10. **完全ローカル処理** — ファイル内容が外部へ送信されることはありません。
11. **フォルダ比較モード** — ヘッダーの「ファイル比較／フォルダ比較」ボタンで切替。2つのフォルダの一覧（**相対パス＋サイズ＋変更日**）を生成して突き合わせ、**追加・削除・変更されたファイル**を差分表示します（ファイル内容は送信・解析されません）。ペアリングは**ファイル名の一致を最優先**し、異名同士の誤ペアリングは行いません。
12. **同じ結果のまとめ表示** — 連続する同じ結果（例：追加が3行連続）は**1枚のカードに集約**され、行範囲と件数をひと目で把握できます（**初期状態で展開表示**、注記は1つのみ表示）。

## 3. 対応ファイル形式

ペインごとに、次のいずれかの方法で入力します。

- **ドラッグ＆ドロップ**（ペイン上に落下）
- **クリックしてファイル選択**（隠しファイルダイアログ）
- **テキストの貼り付け**（編集モードのテキストエリアへ直接貼り付け）

> 「フォルダ比較」モード時は、**フォルダ選択**（フォルダごとの D&D を含む）に切り替わります（→ 5.5）。

| 形式 | 読み込み方法 |
| --- | --- |
| `.docx` | JSZip で `word/document.xml` を解析し、段落（`w:p`）ごとに本文テキストを抽出。失敗時はプレーンテキストとして読込を試行 |
| `.doc` | OLE/CFB（複合ファイルバイナリ）形式を直接解析し、本文テキストを抽出。OLE形式でない場合はエラー表示 |
| `.html` / `.htm` | 文字コードを自動判定→`DOMParser` でパースし、**表示テキスト（innerText）**を比較対象に使用（マークアップは除かれる）。文字コード手動選択UIが表示される |
| `.md` `.txt` `.json` `.csv` `.js` `.ts` `.css` `.log` など | プレーンテキストとして読み込み（拡張子による厳密な制限はなく、上記以外はすべてテキスト扱い） |

> **注意**: `.docx` の読み込みに使用する JSZip、およびフォントは CDN から取得します。読み込み時にのみネット接続が必要な場合があります。取得済みなら以降はオフラインでも比較可能です。

## 5. 使い方（手順）

### 5.1 基本の流れ

1. **`Compare-2-Files.html` をブラウザで開く**
2. **ファイルA を入力** — ペインにドラッグ＆ドロップ、「ファイル選択」ボタン、またはテキストを貼り付け
3. **ファイルB を入力** — 同様に入力
4. **`比較実行` をクリック**（または `Ctrl/Cmd + Enter`）
5. 結果サマリー・差分ブロック一覧・A/B並列ビューに差分が表示されます

### 5.2 入力のヒント

- ファイル未選択の状態でペインをクリックしても選択ダイアログが開きます。
- 貼り付けたテキストはその場で編集できます（編集モード）。
- HTMLを選んだ場合のみ、ペイン下部に**文字コード選択**（自動判定 / UTF-8 / Shift_JIS / EUC-JP / ISO-2022-JP / UTF-16 LE / UTF-16 BE）と**判定結果の出所**（BOM / meta / 推定 / 手動 / 既定値）が表示されます。

### 5.3 結果の読み方

| 表示 | 意味 |
| --- | --- |
| 一致（グリーン） | A・Bで同じ行 |
| 変更（アンバー ↔） | 両方に存在するが内容が異なる行（しきい値以上の類似で対応付け） |
| 削除（レッド −） | Aにのみ存在する行（Bでは削除されている） |
| 追加（ブルー ＋） | Bにのみ存在する行（Aにはない） |
| (空行) | 空の行 |

- **行の色**: 赤系統＝A側の削除・変更、青系統＝B側の追加・変更。
- **文字の色**: 行内で「削除された文字」＝赤、「追加された文字」＝青の細かなハイライト。
- **差分ブロック一覧**: カードをクリックすると折りたたみ/展開。カードにマウスを乗せると、対応する行がビューア側でハイライトされます。
- **同じ結果のまとめ表示**: 連続して同じ種類の結果が出る場合は**1枚のカードにまとめ**られます（例：追加3行 → 「追加 B 2-4（3）」）。カードヘッダに行範囲と件数が表示され、**初期状態では展開されたまま**表示され、ヘッダをクリックすると折りたたみ/展開できます（折りたたみ状態は `+/−` バッジで判別）。中身は各行が `A n:` / `B n:` の行番号付きで並びます。1行だけの差分は従来どおり個別のカードです。
  - グループ内の「**（Aには存在しません）**」「**（Bには存在しません）**」は**カードに1つだけ**表示され、その下に追加・削除された行がまとめて並びます（各行の下に繰り返し表示されません）。

### 5.4 操作（ボタン / ショートカット）

| 操作 | ショートカット | 説明 |
| --- | --- | --- |
| 比較実行 | `Ctrl / Cmd + Enter` | AとBのテキストを比較し、結果を表示 |
| 結果を出力 | `Ctrl / Cmd + E` | 比較結果をHTMLファイルとして保存 |
| クリア | `Ctrl / Cmd + L` | 両ペインの入力と結果をすべて消去 |

### 5.5 フォルダ比較モード

ヘッダーの **「ファイル比較」／「フォルダ比較」** ボタン（「比較実行」の左）でモードを切り替えます。モード切替時は入力と結果がクリアされますが、**「全てクリアしました」の通知は表示されません**（「クリア」ボタン／`Ctrl/Cmd + L` では従来どおり表示されます）。

| 項目 | ファイル比較（既定） | フォルダ比較 |
| --- | --- | --- |
| ペイン見出し | ファイルA： / ファイルB： | フォルダA： / フォルダB： |
| 入力方法 | ファイル選択・D&D・テキスト貼り付け | **フォルダ選択**・フォルダのD&D |
| 入力欄ラベル | テキスト内容 | **ファイルリスト** |
| プレースホルダー | ドラッグ＆ドロップまたはファイルを選択するか、テキストを貼り付けてください | **フォルダAを選択してください** / **フォルダBを選択してください**（ペインごとに別文言） |
| 「比較実行」 | ファイルAとファイルBのテキストを比較 | **フォルダAとフォルダB**を比較 |
| 比較対象 | 行・文字 | **ファイル名・ファイルサイズ・変更日** |

**フォルダ比較の手順**

1. 「フォルダ比較」をクリック
2. 左右のペインに**フォルダを選択**（隠し `<input type="file" webkitdirectory>`）、またはペインへ**フォルダごとドラッグ＆ドロップ**（サブフォルダを再帰的に走査）
3. 「比較実行」— 各フォルダの**相対パス＋サイズ＋変更日の一覧**が生成され、行単位の差分として結果表示されます

生成される1行は次のような形式です（サイズは `size:` の後ろで右寄せ、変更日は `変更日:` の後ろで `YYYY-MM-DD`）。

```text
one.txt  size:       5 B  変更日:   2026-01-02
sub/three.txt  size:       1 B  変更日:   2026-03-04
two.txt  size:      11 B  変更日:   2026-02-03
content.js  size:   17.1 KB  変更日:   2026-09-17
```

英語UI（`JP / EN`）に切り替えると、この日付ラベルは **`Modified:`** になります。

```text
content.js  size:   17.1 KB  Modified:   2026-09-17
```

**結果の読み方（フォルダ比較）**

| 表示 | 意味 |
| --- | --- |
| 一致（グリーン） | A・Bに同じパス・同じサイズ・同じ変更日で存在 |
| 変更（アンバー） | 同じパスだが**サイズまたは変更日が異なる**ファイル |
| 削除（レッド −） | Aにのみ存在（Bから削除されたファイル） |
| 追加（ブルー ＋） | Bにのみ存在（Aにないファイル） |

ペアリングは**ファイル名（相対パス）の一致を最優先**します。ファイル名が一致する行同士は必ず互いに対応付けられ、たとえ類似度が高くても**ファイル名が異なる行同士が対応付けされることはありません**。片側にしかないファイルは、必ず「削除」または「追加」として表示されます。

```text
例）フォルダA: Options.css / Options.html    フォルダB: Options.html
    → Options.css  … 削除（Bには存在しません）
    → Options.html … 変更（A⇔Bで対応付けてサイズ・変更日を比較）
```

> ルートフォルダ名は一覧から除外され、`sub/three.txt` のように**フォルダA/B配下からの相対パス**で比較されます。ファイルの**内容**は比較・送信されません（パス・サイズ・変更日のみ）。「結果を出力」によるHTMLレポート出力もフォルダ比較でも利用できます。
>
> **ドラッグ＆ドロップが動かないとき**: HTMLをローカルファイル（`file://`）としてダブルクリックで開くと、ブラウザのセキュリティ制限によりフォルダの中身を読み取れない場合があります（エラー通知が表示されます）。そのときは「**フォルダ選択**」ボタンから選んでください（クリック選択はローカルファイルでも動作します）。フォルダD&Dは HTTP 経由（ローカルサーバー等）で開いたページで確実に動作します。

## 6. オプション（設定項目）

### 6.1 対応判定しきい値（Matching Threshold）

- **範囲**: 0.30 〜 0.90（刻み 0.05）、**既定値 0.55**
- **効果**: 行どうしの類似度がこの値以上なら「変更」、未満なら「削除＋追加」として扱います。
  - 値を**下げる** → より似ている行も「変更」としてまとめやすい（対応付けが増える）
  - 値を**上げる** → より厳密に。完全に異なる行として扱われやすい
- 設定はブラウザ（localStorage）に保存され、次回起動時も維持されます。

### 6.2 全一致行の表示/非表示

- サマリー横の「全一致行表示／非表示」ボタンで、一致ブロックを一括で開閉できます。
- 個別にカードをクリックしても開閉可能。状態は保存されます。

### 6.3 言語・テーマ

- **JP / EN** ボタンで日本語⇔英語を切替（保存）。
- **太陽/月アイコン**でライト⇔ダークを切替（保存）。

### 6.4 保存される設定（localStorage キー）

| キー | 内容 |
| --- | --- |
| `c2f_lang` | UI言語（`ja` / `en`） |
| `c2f_dark` | ダークモードのON/OFF |
| `c2f_threshold` | 対応判定しきい値 |
| `c2f_equalAllOpen` | 全一致行の表示/非表示状態 |

## 7. 比較アルゴリズム（内部動作）

差分計算は次の多段構成です。

1. **行分割** — CRLF を LF に正規化して行配列を生成。
2. **アンカー決定** — A・Bに**ただ1回だけ完全一致する行**をアンカーとして抽出し、LIS（最長増加部分列）で対応付け。差分の骨格を高速に確定させます。
3. **区間の差分計算** — アンカー間の区間について、行の**類似度**（`Intl.Segmenter` による語分割 → 語単位LCS比）を用いたDPで対応付け。
   - 類似度 ≥ しきい値 → 「変更（replace）」
   - それ未満 → 「削除 / 追加」
4. **文字単位の差分** — 「変更」ペアについて、さらに語/文字単位のLCSで行内ハイライトを生成（長大行は前後固定部の刈り込みで高速化）。
5. **ブロック化** — 連続する一致行を「一致グループ」にまとめ、差分を個別ブロックとして出力。
6. **統計** — 一致・変更・削除・追加の件数、総行数などを集計。

**性能対策**

- 差分計算は **Web Worker**（Blob URL 生成）でバックグラウンド実行し、UIをフリーズさせません。
- Workerが **120秒** でタイムアウトした場合は自動的にメインスレッド（同期モード）へフォールバックします。
- トークン分割・類似度・セグメンタにキャッシュを使用。

## 8. エクスポート（結果を出力）

- 「結果を出力」ボタン（`Ctrl/Cmd + E`）で、比較結果を**単体で開けるHTMLファイル**として保存します。
- ファイル名: `Compare 2 Files 比較結果.html`（日本語UI時） / `Compare 2 Files Result.html`（英語UI時）
- 出力内容:
  - ヘッダー（アプリ名・バージョン）
  - メタ情報（ファイル名・サイズ・文字数・行数）
  - 凡例（削除/変更A＝赤、追加/変更B＝青）
  - A/B並列表（行番号・行ハイライト・文字単位ハイライト付き、JetBrains Mono 等幅フォント）
- 入力がない場合はエラーメッセージを表示します。

## 9. アクセシビリティ

- **スキップリンク**: 「結果へスキップ」（Tabフォーカスで表示）から結果エリアへ直行可能。
- **ARIA**: 各入力欄・ボタンに `aria-label`、ステータス表示に `aria-live="polite"`、差分ブロック一覧に `role="list"`、各カードに `aria-label` を付与。
- フォーカスリング（`focus-visible:ring`）によるキーボード操作の可視化。

---

## 10. 留意事項・制限

- **大容量ファイル**: 差分計算は区間ごとの O(N×M) DP を使用するため、極端に大きいファイルやほぼ全行が異なるファイルでは処理に時間がかかることがあります（Worker 120秒でフォールバック）。
- **`.doc` / `.docx`**: 暗号化・破損・特殊な形式の場合は解析に失敗します。その際は `.docx` や `.txt` で保存し直すか、テキスト貼り付けを使用してください（エラー内容がペイン上に表示されます）。
- **HTML比較**: マークアップ（タグ）は比較対象外となり、表示テキスト（innerText）のみを比較します。
- **文字コード**: HTML以外のテキストはブラウザの既定（UTF-8）で解釈されます。文字コード問題がある場合は HTML 経由で読み込むか、事前に変換してください。
- **ネットワーク**: 初回表示時（フォント）と `.docx` 読込時（JSZip）に CDN へアクセスします。それ以外の比較処理は完全にローカルです。

## 11. トラブルシューティング

| 症状 | 対処 |
| --- | --- |
| 「ファイルAとファイルBのテキストを入力またはドロップしてください」 | 両方の入力を確認してから「比較実行」 |
| 「比較結果がありません」 | 先に「比較実行」を実行してから「結果を出力」 |
| 文字化け（HTML） | 文字コードを手動で選択（Shift_JIS / EUC-JP など） |
| Workerタイムアウト警告 | 自動で同期モードに切替済み。入力を分割するか小さくすると高速化 |
| `.doc` が読めない | `.docx` または `.txt` で保存し直す／テキストを貼り付け |
| 設定を初期化したい | ブラウザのサイト設定から localStorage を削除 |
